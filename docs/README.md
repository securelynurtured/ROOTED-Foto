# Underlag till projektrapporten

Här samlas anteckningar och skärmbilder från utvecklingen av ROOTED Foto.
Materialet används för att beskriva arbetsprocessen, motivera val och visa
relevanta resultat i projektrapporten.

- [Utvecklingslogg](utvecklingslogg.md): genomförda steg, beslut och kontroller.
- [HTML-genomgång](html-genomgang.md): sidornas struktur och elementens funktion.
- [Skärmbilder](screenshots/README.md): bilder, bildtexter och rutin för kommande steg.
- [HTML-validering](validation/01-html-validation.json): sparade svar från W3C Nu Html Checker.
- [Validering av gemensam sidstruktur](validation/02-shared-structure-validation.json): kontroll av fotograferings- och kontaktsidan efter strukturändringen.

## Dokumentation av varje steg

För varje större steg dokumenteras vad som ändrades, varför lösningen valdes,
hur den kontrollerades och vad som återstår. Skärmbilder sparas när de visar
en relevant förändring eller ett kontrollresultat.

## Användning i rapporten

Ett urval av skärmbilderna används som numrerade figurer med bildtext och
hänvisning i rapportens löpande text. Tidiga skärmbilder visar arbetsprocessen;
bilder av den färdiga webbplatsen används för att presentera resultatet.

Skärmbilder av formulär tas med tomma fält eller neutrala testuppgifter.
Datum, utvecklingssteg och webbläsare anges tillsammans med varje skärmbild.
