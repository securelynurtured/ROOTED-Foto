# Skärmbilder – steg 01

Skärmbilderna visar webbplatsens HTML-grundstruktur innan CSS och JavaScript
har lagts till. Webbläsarens standardutseende visas därför i detta skede.

Datum: 2026-11-01. Webbläsare: Google Chrome. Visningsyta: 1440 × 900 CSS-px.
Skärmbilderna togs med Chrome DevTools och Capture full size screenshot.
PNG-bredden är dubbelt så stor som visningsytans bredd på grund av en
pixelkvot på 2. Längre sidor fångas i sin helhet.

Samtliga bilder granskades efter att de sparats. En webbläsarutökning
syntes i den första startsidesbilden, som därför togs om. De sparade
bilderna visar webbplatsen utan utökningens överlägg.

## Bildtexter till rapporten

- Startsidan efter att HTML-strukturen skapats, före formgivning med CSS.
- Fotograferingssidan med beskrivningar av porträtt-, familje- och företagsfotografering.
- Kontaktformulärets HTML-struktur med etiketter och en tillfälligt inaktiverad skicka-knapp.

## Rutin för kommande skärmbilder

1. Öppna sidan i Chrome och välj det utvecklingssteg som ska dokumenteras.
2. Öppna DevTools med Cmd+Option+I och enhetsverktygsfältet med Cmd+Shift+M på Mac.
3. Välj Responsive och ange en bestämd bredd och höjd. Använd samma mått vid jämförelser mellan steg.
4. Öppna More options i enhetsverktygsfältet och välj Capture full size screenshot.
5. Spara bilden i denna katalog med ett nytt stegnummer och ett beskrivande filnamn.
6. Granska bilden och dokumentera datum, webbläsare, visningsmått och vad bilden visar.

Vid senare steg sparas även mobilvyer och relevanta exempel på mobilmeny,
formulärvalidering och andra kontroller. Tidigare steg behålls som jämförelse.

Metoden beskrivs i [Chrome DevTools dokumentation om skärmbilder](https://developer.chrome.com/docs/devtools/device-mode).
