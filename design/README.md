# Designunderlag – ROOTED Foto

Designunderlaget består av wireframes och mockups för desktop och mobil,
exporterade som PNG från Figma. Underlagen visar startsidans planerade design.

## Sparade exporter

| Underlag | Fil | Storlek |
| --- | --- | --- |
| Wireframe för desktop | [wireframe-desktop.png](wireframe-desktop.png) | 1440 × 1640 px |
| Wireframe för mobil | [wireframe-mobile.png](wireframe-mobile.png) | 390 × 2220 px |
| Mockup för desktop | [mockup-desktop.png](mockup-desktop.png) | 1440 × 1640 px |
| Mockup för mobil | [mockup-mobile.png](mockup-mobile.png) | 390 × 2400 px |

Wireframes visar struktur och placering. Mockups visar även färger,
typografi, bilder och tänkt innehåll. PNG-filerna är statiska bilder;
redigerbara lager finns i Figma.

Designunderlaget fungerar som en plan för webbplatsen. Layout och detaljer
kan utvecklas vidare under implementationen.
