# ROOTED Foto

I det här studentprojektet utvecklar jag en webbplats för fotostudion ROOTED Foto i Umeå.

## Syfte

Mitt mål är att göra det enkelt för besökare att förstå tjänsterna,
veta hur en fotografering går till och skicka en förfrågan.

## Målgrupp

Privatpersoner och familjer som önskar naturliga fotografier,
samt småföretag som behöver bilder för sin marknadsföring.

## Tjänster

- Porträttfotografering
- Familjefotografering
- Företagsfotografering

## Planerade sidor

- Start: index.html
- Fotograferingar: fotograferingar.html
- Kontakt: kontakt.html

## Teknik

HTML, CSS och JavaScript utan frontend-ramverk.
