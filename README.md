# ROOTED Foto

I det här studentprojektet utvecklar jag en webbplats för fotostudion ROOTED Foto i Umeå.

## Syfte

Mitt mål är att göra det enkelt för besökare att förstå tjänsterna,
veta hur en fotografering går till och skicka en förfrågan.

## Målgrupp

Privatpersoner och familjer som önskar naturliga fotografier,
samt småföretag som behöver bilder för sin marknadsföring.

## Tjänster

- Porträttfotografering
- Familjefotografering
- Företagsfotografering

## Sidor

- Start: index.html
- Fotograferingar: fotograferingar.html
- Kontakt: kontakt.html

## Teknik

HTML, CSS och JavaScript utan frontend-ramverk.

## Projektstatus

HTML-grundstrukturen för de tre sidorna är skapad. Formgivning med CSS,
responsiv layout, mobilmeny och JavaScript-validering utvecklas i kommande steg.

## Designunderlag

Wireframes och mockups för desktop och mobil finns i [design/](design/README.md).
Underlagen visar startsidans planerade struktur och visuella utformning.

## Lokal förhandsvisning

Starta en lokal webbserver från projektmappen:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Öppna sedan <http://127.0.0.1:8000> i webbläsaren. Servern stoppas med
Ctrl+C i terminalen.
